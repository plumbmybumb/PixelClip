# Where the tarot cards come from

The 22 card images in [`dodal/`](dodal/) (`00-le-mat.png` to `21-le-monde.png`) are the trumps (major arcana) of
**Jean Dodal's Tarot de Marseille** (Lyon, c. 1701).

- **Source:** the Bibliothèque nationale de France's own scans, published on Gallica (ark identifier
  `btv1b10537343h`), as hosted on Wikimedia Commons.
- **Status:** public domain. Wikimedia Commons marks the scans as public domain (its `PD-Art` and `PD-old` tags);
  Commons treats faithful scans of public-domain works as public domain.
- **What this project did:** a script straightened, cropped and tone-adjusted each scan, and the result was resized
  to 236 × 448 pixels. Nothing was redrawn. These are the historical cards, with their age and wear, not a modern
  restoration.
- **Credit line:** Source gallica.bnf.fr / Bibliothèque nationale de France.

note was written.

`dodal/back.png` (the card back) comes from the same set of Bibliothèque nationale de France scans of this deck
and went through the same script as the 22 trumps.

Not recorded in this repository: the individual Wikimedia Commons file name and download date for each card.

The reading texts in this folder (`readings.json`, `reader-en.txt`, `reader-fr.txt`) are the project's own; see the
credits in the root [`README.md`](../../../../README.md#licence-and-credits).
